### 🔥 مشاريع أفتخر بها
بنيت عدة **أنظمة وظيفية (Functional Systems)** ركزت فيها على محاكاة الواقع وإدارة البيانات بذكاء:
- **نظام البنك (Bank System):** إدارة حسابات، عمليات سحب وإيداع، والتعامل مع الملفات.
- **نظام الصراف الآلي (ATM System):** محاكاة كاملة لتجربة المستخدم مع تأمين البيانات.
- **تحديات الخوارزميات:** قمت بحل مئات المشكلات البرمجية لتقوية عضلة المنطق عندي.
